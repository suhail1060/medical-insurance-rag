To ensure compliance with statutory claims auditing standards and prevent administrative rejections, all medical claims submitted to Apex Health Plans must contain complete documentation supporting the clinical necessity and financial details of the services rendered.

Mandatory Claim Elements:
1. Provider Identification:
- Servicing provider's full legal name, professional credentials (MD, DO, DPT, LCSW), and physical service clinic address.
- Valid 10-digit National Provider Identifier (NPI).
- Federal Tax Identification Number (TIN) or Employer Identification Number (EIN).

2. Standardized Clinical Coding:
- Diagnostic Codes: Current ICD-10-CM clinical diagnosis codes specifying primary and secondary medical conditions, coded to the highest level of specificity (minimum 4 to 7 digits).
- Procedure Codes: Current Procedural Terminology (CPT) or Healthcare Common Procedure Coding System (HCPCS) codes identifying each medical procedure, diagnostic test, or injection.
- Modifiers: Required two-character billing modifiers (e.g., Modifier -25 for distinct evaluation services, or Modifier -59 for distinct procedural services) where applicable.

3. Service Encounter Details:
- Date of service for each line item (including admission and discharge dates for inpatient stays).
- Place of service code (e.g., Code 11 for office, Code 21 for inpatient hospital, Code 22 for outpatient hospital, Code 23 for emergency room).
- Detailed unit counts (e.g., minutes for physical therapy units, milliliters for specialty medications).
- Gross billed charge for each discrete procedural code.

4. Proof of Member Payment:
For direct reimbursement to members, proof of full payment must accompany the itemized claim. Acceptable documentation includes:
- Photocopy of cleared front and back cancelled check.
- Bank statement or credit card statement highlighting the specific provider transaction.
- Provider's stamped receipt showing a zero balance due and payment method.

Claims lacking any mandatory data field will be returned via CARC Code CO-16 (Claim lacks required information) within fourteen (14) days.
